# Generated datasets

The generator publishes verified datasets here as `<name>.json`. They are opt-in,
ignored by Git, and do not change the 150-task benchmark or retained walking set.
Play them with `?trainingDataset=<name>.json`; use the same basename with MCP's
`--training-dataset` option. Configuration, provenance, controller proofs and
resumable partial output are saved in the generator's `--output` directory.

See [generation.md](../../docs/generation.md) for commands and supported templates.
